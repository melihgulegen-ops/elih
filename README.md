# İstizan — Görev, İstizan ve Not Takibi

Koyu, ay yıldız motifli tema. Görevler (tarih, saat, öncelik, plan), İstizan (Yatan, İade, Alınan Malzemeler), Notlar ve PDF/Excel raporları. Kayıtlar cihazın tarayıcı hafızasında saklanır.

## Çalıştırma
```
bun install
bun run dev
```
